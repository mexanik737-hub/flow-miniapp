## Постоянная регрессия PR #5

Для статического vanilla JS приложения выбран встроенный `node:test` плюс VM fixtures: это не требует установки зависимостей и блокирует все внешние запросы. `shopEscape(JSON.stringify(id))` остаётся транспортным паттерном для inline HTML-атрибутов, покрытым round-trip fixtures. Browser CI не включён: в текущем checkout нет Playwright package, npm отсутствует, а локальная браузерная страница автоматически обращается к внешнему Apps Script при загрузке.

Недопустимые/отсутствующие денежные и аналитические значения показываются как `—`; числовые строки преобразуются явно при суммировании. Ошибочные поля не превращаются молча в `0 ₽`. ID `0` считается существующим ID в редакторах; `null`/`undefined` остаются маркерами нового объекта.
