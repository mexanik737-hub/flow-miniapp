# Floral Glass UI — автономный прототип

Откройте `index.html` в браузере. Сборка, сервер, внешние библиотеки и сетевые запросы не нужны.

## Содержимое
- Каталог с локальными демонстрационными товарами, фильтрами и карточкой деталей.
- Корзина, выбор количества и отдельный макет оформления.
- Root-панель: сводка, заказы, товары, клиенты и статистика.
- UI Kit с общими состояниями компонентов.
- Светлая и тёмная темы; сохранение темы и корзины только в `localStorage` этого прототипа.
- Адаптивность от 320 px, focus-visible, семантические кнопки и reduced-motion.

Все данные тестовые. API, Telegram, внешние сервисы, оплата и действующее приложение не подключены. Навигация в прототипе ограничена Каталогом, Корзиной и Root; отдельных вкладок «Главная», «Заказы», поиска, избранного и кабинета курьера нет.
