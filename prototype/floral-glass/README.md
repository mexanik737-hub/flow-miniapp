# Floral Glass UI — автономный интерактивный прототип

Самостоятельный визуальный стенд. Он не импортирует код действующего приложения, не обращается к API и не подключает Telegram или платёжные сервисы.

## Локальный просмотр

Из корня репозитория запустите:

```bash
python3 -m http.server 8000 --directory prototype/floral-glass
```

Откройте `http://localhost:8000`. Для остановки сервера нажмите `Ctrl+C`.

## Что внутри

- Каталог: фильтры, Bento-подборки, фотографии и универсальные карточки.
- Детали товара: группы опций, зависимый выбор, надбавки к цене, недоступное состояние.
- Корзина и оформление: варианты в строке, изменение количества, доставка/самовывоз, локальный финальный сценарий.
- Root: заказы, каталог, клиенты, рассылки, статистика и FAQ.
- UI Kit: состояния кнопок, поля и селекторы, ProductCard, административные строки, состояния загрузки/ошибки, Dialog, ConfirmDialog, BottomSheet, FullscreenSheet и вложенная модалка.
- Все изображения стенда находятся в `assets/`. Состояние темы и корзины сохраняется в `localStorage` только на локальном origin.

## Структура

- `index.html` — оболочка экранов и модальных слоёв.
- `styles/tokens.css` — цветовые, размерные и motion-токены.
- `styles/components.css` — общие поверхности и компонентные состояния.
- `styles/layout.css` — экранные композиции и брейкпоинты.
- `styles/motion.css` — анимация, reduced motion, high contrast.
- `js/data.js` — локальные демо-данные.
- `js/components.js` — view-model и переиспользуемые рендер-функции.
- `js/app.js` — состояние и взаимодействия.
- `qa/` — результаты responsive/functional QA и реальные скриншоты Chromium.

Карточки не проверяют конкретные названия товаров. У модели могут быть 0–несколько фотографий, бейджей и групп опций; поддерживаются зависимые варианты, надбавки, длинный заголовок, отсутствие товара и fallback изображения.

## Ограничения демо

Формы редакторов, рассылок и FAQ показывают компоненты и локальные состояния; они не сохраняют бизнес-данные. Заказ не отправляется и не оплачивается. Данные Root демонстрационные. Это визуальный прототип, не интеграция.
